# 自動正體中文化

瀏覽簡體中文網頁時，自動把頁面文字轉成正體中文。不需要手動操作，打開頁面就直接轉好。

---

## 安裝前準備

這個腳本需要搭配「使用者腳本管理器」才能運作。請根據你的瀏覽器選擇安裝：

| 瀏覽器 | 推薦擴充功能 | 安裝連結 |
|--------|-------------|----------|
| Firefox | Tampermonkey | [Firefox 附加元件](https://addons.mozilla.org/firefox/addon/tampermonkey/) |
| Chrome | Tampermonkey | [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |

> 安裝完後，瀏覽器右上角會出現 Tampermonkey 的圖示（一個方形章魚）。

---

## 安裝腳本

1. 確認 Tampermonkey 已安裝完成
2. 點擊下方連結：

   👉 **[安裝 auto-chs-to-cht.user.js](auto-chs-to-cht.user.js)** （在 Github 上點擊後請再點擊 Raw）

3. Tampermonkey 會自動跳出確認頁面，點「安裝」即完成

---

## 使用方式

**安裝後不需要任何設定**，腳本會自動判斷：

- 打開一個簡體中文網頁 → 自動轉換成正體中文
- 打開正體中文、英文或其他語言的網頁 → 不做任何動作

### 判斷邏輯

腳本依序用以下方式判斷：

1. **宣告語言優先**：若網頁宣告為簡體中文（如 `zh-CN`、`zh-Hans`、`zh-SG`），整頁直接進入完整轉換模式。
2. **混合／繁體／英文網頁特徵快篩**：若網頁未宣告為簡體（如 YouTube、GitHub 等），腳本透過簡體專有字與常見詞組快速過濾，僅對含有簡體內容的節點進行動態轉換。

### 轉換範圍

- 頁面全部文字（包含開放式 Shadow DOM 內容）
- 頁面標題（支援 SPA 頁面動態更換標題）
- 搜尋框提示字、圖片說明文字（placeholder、alt、title、aria-label）
- 動態載入的新內容（如無限捲動、Ajax 載入的留言，透過佇列批次排程避免掉幀）

### 不會動到的地方

- 程式碼區塊（`<code>`、`<pre>` 等）
- 可編輯的輸入框（避免影響你正在打的字）
- SVG 圖形、數學公式

## 常見問題

**Q：為什麼某些簡體詞沒有被轉換？**

部分繁簡共用字（如「后、里、面、干」）需依賴前後詞組判斷，極短或未收錄的獨立詞彙可能被快篩略過。

**Q：轉換後有些詞彙怪怪的？**

少數情況可能有誤轉。

**Q：我想暫時關閉怎麼辦？**

點瀏覽器右上角的 Tampermonkey 圖示 → 找到這個腳本 → 點選「停用」即可暫時關閉。
